
# Boolean Expressions and Comparison Operators

## Assignment vs. Comparison

```text
=   Assignment operator
    "Assign the value on the right to the variable on the left."

==  Comparison operator
    "Compare two values."
```

Examples:

```python
number = 10      # Assign 10 to number

10 == 10         # True
10 != 10         # False
10 > 5           # True
10 < 5           # False
10 >= 10         # True
10 <= 5          # False
```

## Important Rule

Whenever you see a comparison operator, the expression evaluates to a Boolean.

Comparison operators:

```text
==   Equal to
!=   Not equal to
>    Greater than
<    Less than
>=   Greater than or equal to
<=   Less than or equal to
```

Every comparison returns either:

```text
True
False
```

---

## Example

Python evaluates this:

```python
15 == 15
```

as:

```python
True
```

So this:

```python
isEqual = (15 == 15)
```

becomes:

```python
isEqual = True
```

The same idea exists in most programming languages.

### Python

```python
isEqual = (15 == 15)      # True
```

### C++

```cpp
bool isEqual = (15 == 15);    // true
```

### Java

```java
boolean isEqual = (15 == 15); // true
```

### JavaScript (Node.js)

```javascript
let isEqual = (15 === 15);    // true
```

# Example: Checking if a Number is Even

Long version:

```python
if (number % 2 == 0):
    even = True
else:
    even = False
```

Short version:

```python
even = (number % 2 == 0)
```

These are equivalent.

## Step by Step

Suppose:

```python
number = 8
```

Python evaluates:

```python
number % 2 == 0
```

Step 1:

```python
8 % 2
```

becomes:

```python
0
```

Now Python has:

```python
0 == 0
```

This comparison evaluates to:

```python
True
```

So Python finally assigns:

```python
even = True
```

---

Now suppose:

```python
number = 7
```

Step 1:

```python
7 % 2
```

becomes:

```python
1
```

Now Python has:

```python
1 == 0
```

This comparison evaluates to:

```python
False
```

So Python finally assigns:

```python
even = False
```

## Key Idea

The `%` operator returns a number.

The comparison operator (`==`) turns the expression into a Boolean by asking a yes/no question.

```python
number % 2        # Returns a number

number % 2 == 0   # Returns True or False
```

A good way to think about it is:

> Comparison operators (`==`, `!=`, `>`, `<`, `>=`, `<=`) create Boolean expressions. Every Boolean expression evaluates to either `True` or `False`.
