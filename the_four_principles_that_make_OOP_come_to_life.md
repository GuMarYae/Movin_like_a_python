
## **The Four Principles of Object Oriented Programming (OOP)**

or, if you want something a little more memorable:

## **The Four Core Principles That Make OOP Work**

Then list them:

1. **Abstraction:** Separating the use of a function from its implementation.
2. **Encapsulation:** The details of information are hidden from the user or client that invokes the function. Also called  **information hiding** .
3. **Inheritance:** A new class can inherit the data and functions of an existing class.
4. **Polymorphism:** The same function or method can have different implementations depending on the object or class that uses it.
